# Final Capstone Project

This project is an **Admin Dashboard** designed to manage event information efficiently. It enables administrators to perform full **CRUD (Create, Read, Update, Delete)** operations on events.

## Features

### Create

Administrators can create new events by providing all the necessary event details.

### Read

Administrators can view and access a list of all existing events.

### Update

Administrators can edit and update event information whenever changes are required.

### Delete

Administrators can remove events that are no longer needed or have been canceled.

## Summary

The dashboard provides a simple and efficient interface for managing events, allowing administrators to create, view, modify, and delete event records with ease.
